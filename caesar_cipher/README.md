# 🔐 Caesar Cipher Streamlit Chatbot

An interactive chat application built with **Streamlit** that encodes and decodes text using the classic **Caesar Cipher** algorithm.

---

## ✨ Features

- **Interactive Chat Interface:** Send text messages and receive ciphered output in real time.
- **Dynamic Controls:** Toggle between **Encode** and **Decode** modes and adjust shift values (1–25) on the fly via the sidebar.
- **Full Character Support:** Preserves uppercase/lowercase letter casing, punctuation, numbers, and spaces.
- **Session History:** Retains the conversation thread with a one-click chat clear button.
